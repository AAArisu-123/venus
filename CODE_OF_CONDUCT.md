# Code of Conduct

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), adapted for a
small personal project.

## Expected behavior

- Be respectful and assume good faith.
- Give actionable technical feedback; critique code, not people.
- Respect privacy. Do not publish anyone's chat logs, openids, keys or other
  personal data.
- Keep discussions on topic and free of harassment, discrimination, threats or
  sexual attention.

## Unacceptable behavior

- Harassment, insults, slurs or sustained disruption.
- Publishing private information without permission.
- Using the project to build non-consensual impersonation, surveillance or
  abusive companion behavior.
- Any conduct that would make participation unsafe or unwelcome.

## Scope

This applies to issues, pull requests, discussions and any other project
space, as well as public interactions where someone represents the project.

## Enforcement

Maintainers may edit or remove content, close threads, or block accounts that
violate this code. Decisions are made in good faith and focus on keeping the
project usable and safe.

To report a conduct issue, contact the maintainer through their GitHub profile
without including unnecessary personal data. Reports are handled privately.
