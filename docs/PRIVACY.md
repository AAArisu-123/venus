# 隐私与安全

这个项目没有账号、加密和内容审核，就是一个跑在自己电脑上的程序。别把它放到公网，也别拿它当多用户服务。

## 数据放在哪里

| 位置 | 内容 | 是否提交到 Git |
| --- | --- | --- |
| `.env` | 模型密钥、QQ 凭据 | 否（已忽略） |
| `data/venus.sqlite3` | 聊天历史、长期记忆、画像、心情、主动计划 | 否（已忽略） |
| `data/pairing.sqlite3` | QQ 配对码与已批准用户 | 否（已忽略） |
| `data/qq-credentials.json` | 扫码得到的 AppID / AppSecret | 否（已忽略） |
| `logs/qq-service.log` | 启动、连接状态和错误类别 | 否（已忽略） |

SQLite 数据库和日志都是明文。`.gitignore` 只能降低误提交概率，不能替代磁盘加密、系统账户隔离或备份加密。

## 什么会离开本机

- **模型服务**：人设、当前消息、选中的历史、画像、长期记忆摘要、生活小事和心情描述会发送给你配置的模型服务商。
- **联网搜索（可选，默认关闭）**：开启后，角色、近期聊天和记忆会发送给 DeepSeek，模型可能据此生成搜索词并交给搜索服务商。
- **QQ 平台（可选）**：消息文本和 openid 会经过腾讯 QQ 接口。
- **不会主动上传**：项目本身没有遥测、统计或云端同步。

请先阅读模型与搜索服务商的数据处理条款，再决定发送什么内容。

## 发送前过滤

`privacy.py` 会拦截高置信度的：

- 私钥、API 密钥、访问令牌
- 密码、验证码
- 身份证号、银行卡号
- 手机号、邮箱

命中后消息不会发送、不会保存，也不会在提示中回显原值。历史、长期记忆和画像在发给模型前还会再做一次脱敏，避免以前保存的敏感内容再次外发。

过滤基于规则，**不能保证完整**。不要向机器人发送密码、密钥、证件照片或他人的私人信息。

## 日志

- QQ 后台服务只记录启动、网关状态和错误类别。
- 不记录聊天正文、提示词、密钥或 openid 明文。
- 日志按大小轮转；实际路径可用 `python -m venus.doctor` 查看。
- 如果 `%LOCALAPPDATA%\Venus\logs` 不可写，会依次回退到系统临时目录和项目 `logs/`。

## 本地加固建议

- 运行 `powershell.exe -NoProfile -File .\scripts\harden_private_files.ps1`，把 `.env`、`data/` 和根目录 `.txt` 的 NTFS 权限限制到当前 Windows 用户。
- 不要把 `data/`、`.env` 上传到网盘、聊天窗口或代码仓库。
- 怀疑密钥泄漏时，立即在模型服务商和 QQ 开放平台轮换密钥，并检查本地日志与提交历史。
- 删除整个 `data/venus.sqlite3` 可以清除聊天、记忆和画像，但也会删除全部角色数据；请先备份。
- 分享截图或日志前，先检查是否包含 openid、路径、密钥或聊天内容。

## 访问控制

- QQ 端默认拒绝未知用户：要么配置 `QQ_ALLOWED_OPENIDS`，要么使用本地配对码审批。
- 配对码有有效期，审批在机主本机完成。
- 程序没有账户密码体系，`--user` 只是本地数据分组标识，不是身份认证。
- **绝不要**把本项目直接暴露到公网或作为多租户服务运行。

## 报告安全问题

请不要在公开 issue 中贴出密钥、聊天记录或可利用细节。报告方式见 [SECURITY.md](../SECURITY.md)。
